# 单词速查 · 考研英语大纲词汇查询系统

本项目为作者的首个项目，如有错误或不便还请见谅
目前功能不完善，部署操作较麻烦，后续会继续修改

「搜索即服务，详情即网络」——在极简视觉中完成从"模糊输入"到"精确查询"再到"词义网络漫游"的完整闭环。

- **前端**：Vue 3 + Vite + vue-router（SPA，平滑路由过渡）
- **后端**：FastAPI + Python（内存索引，查询 O(1)/O(log n)）
- **数据**：`考研英语大纲词汇5500.csv`（5243 个词条，含词性分组释义与动词变形）

## 快速开始

### 1. 后端

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate    # macOS / Linux
pip install -r requirements.txt

# （可选）重建索引 —— 仅当更新了词汇 CSV 或精选种子后才需要
python scripts/build_index.py [词汇表.csv路径]

# 启动服务
uvicorn app.main:app --reload --port 8000
```

> 本仓库已附带一个预置好的 `backend/.venv`（含 fastapi/uvicorn 及全部依赖），
> 可直接运行：`backend\.venv\Scripts\python -m uvicorn app.main:app --port 8000`。

启动后接口即用：`http://127.0.0.1:8000/docs`（Swagger 文档）。

### 2. 前端

```bash
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173` 即可使用（开发服务器已将 `/api` 代理到后端 8000 端口）。

生产构建：`npm run build` 后 `npm run preview`（预览已含代理，直接部署时请将后端接口配置到同域或开启后端 CORS）。

> 不启动完整构建时，也可用静态校验快速检查源码：
> `node scripts/validate.mjs`（基于 @vue/compiler-sfc 与 @babel/parser，无需构建）。

### 3. 桌面置顶小组件（Electron，可覆盖其他应用窗口）

网页内的小组件无法浮在其他程序窗口之上（浏览器安全模型），因此另配了一个极薄的
**Electron 壳**：无边框、透明、置顶（alwaysOnTop）的小窗口，显示同一个查词小组件。

```bash
# 前置：后端已在 8000 运行；前端构建产物（含 widget.html）
cd frontend && npm run build

# 运行桌面小组件
cd ..\electron
npm install          # 首次（下载 Electron，约 100MB）
npm start
```

- 窗口默认出现在屏幕右下角附近，**按住搜索条可拖动**；窗口可**自由调整大小**（像浏览器窗口一样
  拖动边缘/角落，范围 240~900 宽、54~620 高），内容 100% 撑满窗口、面板自适应滚动、永不截断；
  打开结果面板时窗口自动长高以容纳完整内容（释义/词组/备注全部可见）；
- **清空按钮为文字按钮「清空」**；
- **与设置页联动**：设置 → 桌面小组件 的开关通过 `POST /__widget__/state` 远程控制
  窗口的显示/隐藏（状态持久化到 `electron/widget-state.json`，开关同步、✕ 隐藏即关闭）；
  进程在窗口隐藏后保持存活，随时可被重新开启；
- 点击结果"详情"会用系统浏览器打开完整应用页；
- Electron 内置静态服务 `127.0.0.1:8088`：`/widget.html` 为小组件页、`/` 为完整应用、
  `/api/*` 自动代理到后端 8000（无需改动后端 CORS）。

#### 运行环境检测（桌面小组件的启用条件）

| 运行环境 | 检测方式 | 桌面小组件（覆盖其他窗口） |
|---|---|---|
| 本地部署（Electron 壳） | 存在 `window.widgetApi` 或 UA 含 `Electron` | **可用** |
| 浏览器（本机访问 localhost） | 无 widgetApi，hostname 为 localhost/127.0.0.1 | **已禁用**（需 Electron 壳运行） |
| 浏览器（远程部署 hosted） | 无 widgetApi 且 hostname 非本机 | **已禁用** |

- 检测逻辑位于 `frontend/src/env.js`（`isElectron` / `isLocalHost` / `isRemoteBrowser`）；
- 设置 → 桌面小组件 页面顶部显示当前环境状态条，禁用时给出说明与启用方式；
- 「网页内小组件」（页面内浮动查词栏）不受影响，浏览器与本地部署均可使用；
- 在浏览器中直接打开 `widget.html` 会显示"浏览器预览模式"提示，仅作界面预览。

## 后端 API

| 接口 | 说明 |
|---|---|
| `GET /api/health` | 健康检查，返回词条总数 |
| `GET /api/search?q=ab&limit=8` | 联想搜索：英文=前缀 > 子串 > 模糊；中文=词项精确 > 词义前缀 > 词义包含 |
| `GET /api/word/{word}` | 单词详情：释义分组 / 动词变形 / 近义词 / 形近词 / 备注 / 前后词（支持中文反查） |
| `GET /api/random?exclude=word` | 随机返回一个单词（详情页随机切换模式用，可排除当前词） |
| `GET /api/spelling?q=abandn` | 拼写建议（404 时前端附带展示） |
| `GET /api/admin/db` | 词库信息（文件名 / 词数 / 是否更新中） |
| `GET /api/admin/status` | 索引更新状态（前端轮询用） |
| `POST /api/admin/words` | 添加单词 → 自动重建索引 |
| `PUT /api/admin/words/{word}` | 修改单词 → 自动重建索引 |
| `DELETE /api/admin/words/{word}` | 删除单词 → 自动重建索引 |
| `POST /api/admin/rebuild` | 手动触发一次索引更新 |
| `GET /api/admin/export` | 下载当前词库 CSV（带 BOM，可用 Excel 批量编辑） |
| `POST /api/admin/import` | 用 CSV 文本整体替换词库（自动备份 .bak）→ 重建索引 |
| `PUT /api/admin/words/{word}/notes` | 保存/清除单词备注（轻量，仅写 CSV 备注列，不重建索引） |
| `GET /api/notes` | 所有带备注的单词（备注查看面板用） |

查询无结果时返回 404 + 拼写建议列表，前端展示"未找到该词"与可点击的建议链接。

> 词库管理（增/改/删/导入）直接写回根目录的 `考研英语大纲词汇5500.csv`，随后在**后台线程**
> 自动重建索引（约 30 秒），完成后内存索引热切换，无需重启服务；导入前旧文件自动备份为
> `考研英语大纲词汇5500.csv.bak`。CSV 列顺序：单词,词性1,释义1,…,词性5,释义5,现在分词,过去式,
> 过去分词,词组,备注。
> 词组列格式：多个词组用 `；` 分隔，每个词组为 `英文 | 中文释义 | 备注`（英文必填，释义/备注可空）。

## 近义词 / 形近词算法（预计算策略）

项目采用**「更新词表时执行一次匹配并写入文件」**的方案：

- `scripts/build_index.py` 读取词汇 CSV 与精选种子，运行以下算法，将结果写入
  `data/synonyms.json` 与 `data/similar.json`；
- 服务启动时把索引整体载入内存，之后每次查询只是字典/二分查找，零重复计算；
- 将来补充单词表或精选种子后，只需重新执行一次构建脚本，无需改服务代码。

### 近义词（词义重叠 + Dice 系数）

1. 将每个词的中文释义切分为「词项」（如 "离弃，丢弃；遗弃；抛弃；放弃" 拆为 5 个词项，
   并做归一化：去除句首助词"使/对/把…"、句尾"的"）；
2. 建立词项倒排索引（词项 → 单词集合）；
3. 对候选词计算 Dice 系数 `2·|A∩B| / (|A|+|B|)`；
4. 保留规则：`Dice ≥ 0.45`，或 `共享词项 ≥ 2 且 Dice ≥ 0.30 且候选词项集 ≤ 目标词项集 2 倍`；
   同词性再加 0.1 分；
5. 精选种子（`curated_synonyms.json`）以满分 1.0 合并，保证常见词有高质量结果。

### 形近词（编辑距离 ≤ 2）

1. 按词长分桶（只与长度差 ≤ 2 的候选比较）；
2. 先用「字符多重集」必要门控剪枝（编辑距离 ≤ 2 ⇒ 较短词与较长词至少有
   `len(短) − 2` 个相同字符），再计算带早停的 Levenshtein 距离；
3. 精选易混词对（`curated_similar.json`，如 adapt/adopt/adept、principal/principle、
   affect/effect）永远排在最前。

### 性能

- 构建：近义词 ~0.04s，形近词 ~23s（一次性成本）；
- 查询：联想与详情均为内存查找，单次 < 1ms。

## 前端功能对照

- 顶部粘性搜索栏：巨圆角 + 投影；放大镜图标；输入后出现清空按钮；
- **中英文互查**：搜索框右侧「EN / 中」切换查询语言（localStorage 记忆）；
  - EN 模式：输入英文单词；
  - 中模式：输入中文释义（如"放弃"），联想下拉直接列出对应英文单词，点击/回车进入详情；
  - 中文反查命中后自动跳转到规范英文词条，搜索栏同步显示英文单词；
- 智能联想下拉：左侧单词 + 右侧"词性 · 简短释义"，最多 8 条，支持 ↑/↓/回车/ESC 键盘操作；
- 单词详情：衬线大词头 + 收藏星标（替换原发音按钮）、词性分组释义、
  动词变形标签、近义词/形近词词块（悬停显示完整释义、点击跳转、按压下沉动效、浏览器返回可回溯）、
  **词组卡片**（固定搭配/常用词组合并：每词组含「英文/中文释义/备注」三栏，按显示空间自适应 1~3 行；
  标题旁 ✎ 铅笔可**内联编辑**，以三空栏形式添加/修改词组）、
  **左右切换单词**（页面两侧悬浮箭头，按偏好顺序或随机切换）；
- 收藏：**分文件夹收藏** —— 详情页 ☆ 弹出文件夹选择器（可多选、可即时新建文件夹、文件夹可命名/重命名/删除），
  一个单词可同时收藏进多个文件夹；左下角「收藏查看」按钮（位于设置按钮上方、风格一致）按文件夹展示，
  localStorage 持久化（旧版收藏自动迁移到"默认收藏"文件夹）；
- **备注**：详情页底部备注卡片（添加/修改/清除，保存即生效，不触发索引重建）；左下角「单词备注」按钮
  （位于收藏按钮之上、风格一致）列出所有带备注的单词（点击跳转、可清除备注）；备注存入 CSV「备注」列；
- 空状态："未找到该词" + 拼写建议链接；加载态：旋转指示；
- 页面切换：淡入 + 轻微上移的 SPA 过渡；
- 响应式：容器 `max-width` + `clamp()` 字号 + 断点适配移动端；
- **设置（弹出窗口）**：点击左下角齿轮打开居中弹出窗口，**左侧导航、每个功能一个页面**：
  - **显示**：字号（小/中/大）；
  - **偏好**：详情页左右切换方式（顺序 / 随机）；
  - **数据库 · 词库管理**：CSV 导出 / 上传整体替换（自动备份 .bak）、单个添加 / 修改 / 删除单词
    （词性组最多 5 组、动词三态、词组），操作后自动触发索引更新并显示进度、手动更新索引；
  - **桌面小组件**：开关 + 重置位置；
- **桌面小组件（网页版）**：开启后页面上出现一个**可拖动**的浮动查词栏（位置自动保存）——直接输入英文/中文查词，
  联想下拉与**查词结果面板会根据小组件所在位置自动显示在其上方或下方**（上下空间哪边更大显示在哪边），
  点击结果可跳转详情页，关闭按钮或设置开关均可隐藏；
- **桌面小组件（Electron 版）**：见上方「快速开始 · 3」，可置顶显示在其他应用窗口之上。
